# Sample CVE Dashboard for Threat Intelligence
LevelBlue mimics and showcases a real world dashboard with an internal database.<br>

## Disclaimer
* No propriety information and code was used in the making of this dashboard
    * Benji Inc. is a fictional company named after my cat. LevelBlue is a fictional dashboard that combines the word "level" with my cat's middle name, blue.
* The source code of this dashboard uses an open source dashboard template made by secondtruth. To view the template, credit, and licenses, please redirect [here](https://github.com/secondtruth/startmin).
* Data is derived from [Google's Project Zero's spreadsheet](https://projectzero.google/0day.html) from the years 2023 through 2026. All data is public information.

## Features

* Custom SQL queries using AlaSQL
* Navigation Bar
* Charts derived from data source
* Sample Employee Page
